Count the claimant currently recorded on each game, rather than logging every claim event permanently.

**Why:** The owner chose recorded game assignments; released claims are cleared and cannot be reconstructed from current data.

**How to apply:** Derive totals from recorded per-game claimant fields for the selected team. Do not add permanent claim-history tracking or infer released claims without new direction.

Captains must be able to select particular players for game duties; self-claiming alone is insufficient.

**Why:** The owner explicitly requested, “Captains need to be able to assign the duties to particular players.”

**How to apply:** Keep captain assignment and reassignment alongside voluntary self-claiming. Count whichever player is currently assigned, regardless of who made the assignment.
