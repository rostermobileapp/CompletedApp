---
name: Homepage positioning
description: The emotional benefit that should lead Roster homepage design work.
---

Lead the homepage with enjoying time off the ice together, rather than spending that time on team admin.

**Why:** The user approved the initial scroll concept as a start, then emphasized that the main benefit is time with each other, not merely less administration or more playing time.

**How to apply:** Put the teammate-togetherness message before management features in homepage concepts. Keep preview work isolated until the user asks for live integration.

Position the hero headline high beneath the navigation; keep supporting content lower with a noticeable gap.

**Why:** The user clarified that “higher up on the page” means visibly higher page placement, not simply a smaller headline margin.

**How to apply:** Adjust the hero's top spacing when changing this placement, and verify the navigation does not cover the headline on desktop or mobile.

Keep Features, Pricing, About, and Partners discoverable when redesigning the homepage.

**Why:** The user explicitly objected to losing these existing destinations in the new homepage design.

**How to apply:** Preserve navigation access to all four as separate page previews when redesigning the site. Homepage sections alone do not satisfy a request to redesign these pages.

Preserve the existing playoff-bracket automation animation exactly when restyling the Features page.

**Why:** The user specifically requested the same animation as the current site, not a static bracket or a newly designed sequence.

**How to apply:** Reuse the original animation, including timing and visual progression; apply the new theme to the surrounding page rather than changing the animation.

Keep the homepage hero photo fade and the story section immediately below it pure black for a seamless transition.

**Why:** The user chose to make the next section black rather than preserve its former dark-navy background, so the photo could fade to true black without a visible seam.

**How to apply:** Keep the hero overlay’s final stop and the following story section backgrounds synchronized at `#000` when adjusting this transition.

Hero word changes must use actual split flaps: the top half folds downward around a center hinge, not a vertically scrolling reel or a rotating whole glyph. Use black letter tiles with very thin white borders.

**Why:** The user rejected both the earlier single-glyph animation and alphabetical scrolling approximation. Changed letters should start together and advance forward alphabetically (A→D is 3 flips; A→R is 17).

**How to apply:** Preserve the physical half-panel folding and alphabetic step counts when refining motion. Keep reduced-motion and screen-reader behavior intact.
