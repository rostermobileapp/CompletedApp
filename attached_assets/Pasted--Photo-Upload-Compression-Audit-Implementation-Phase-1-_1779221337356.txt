## Phase 2: Implementation (only after I approve Phase 1)

If audit confirms compression is missing or incomplete, implement the following:

### 2.1 Install dependency
Add `browser-image-compression` to package.json.

### 2.2 Create a shared compression utility
Create `src/lib/imageCompression.js` (or `.ts` if the project is TypeScript — match the existing convention):

```javascript
import imageCompression from 'browser-image-compression';

// Compression presets keyed by use case
const PRESETS = {
  avatar:      { maxSizeMB: 0.3,  maxWidthOrHeight: 512,  useWebWorker: true, fileType: 'image/jpeg', initialQuality: 0.85 },
  rosterPhoto: { maxSizeMB: 0.4,  maxWidthOrHeight: 1080, useWebWorker: true, fileType: 'image/jpeg', initialQuality: 0.85 },
  teamLogo:    { maxSizeMB: 0.2,  maxWidthOrHeight: 600,  useWebWorker: true, fileType: 'image/jpeg', initialQuality: 0.9  },
  leagueAsset: { maxSizeMB: 0.5,  maxWidthOrHeight: 1600, useWebWorker: true, fileType: 'image/jpeg', initialQuality: 0.85 },
};

export async function compressImage(file, preset = 'rosterPhoto') {
  // Skip compression for non-images (defensive)
  if (!file.type.startsWith('image/')) return file;

  // Skip if already smaller than target
  const options = PRESETS[preset] || PRESETS.rosterPhoto;
  if (file.size <= options.maxSizeMB * 1024 * 1024) return file;

  try {
    const compressed = await imageCompression(file, options);
    console.log(`[compressImage] ${file.name}: ${(file.size/1024/1024).toFixed(2)}MB → ${(compressed.size/1024/1024).toFixed(2)}MB`);
    return compressed;
  } catch (err) {
    console.error('[compressImage] failed, uploading original:', err);
    return file; // Fail open — never block an upload because of compression
  }
}
```

### 2.3 Wire compression into every upload entry point identified in Phase 1
For each entry point, insert a `compressImage(file, '<preset>')` call BEFORE the Supabase upload call. Pick the preset based on the upload context:
- User profile photo / avatar → `avatar`
- Roster/player photo → `rosterPhoto`
- Team logo → `teamLogo`
- League banner, event flyer, generic image → `leagueAsset`

Example transformation:

BEFORE:
```javascript
const { data, error } = await supabase.storage
  .from('avatars')
  .upload(path, file);
```

AFTER:
```javascript
const compressed = await compressImage(file, 'avatar');
const { data, error } = await supabase.storage
  .from('avatars')
  .upload(path, compressed);
```

### 2.4 HEIC handling
`browser-image-compression` does NOT handle HEIC natively. iPhones often deliver HEIC from the file picker. Add a check:
- If `file.type === 'image/heic'` or filename ends in `.heic`/`.heif`, the compression library will throw.
- Catch this case and either:
  - (a) Reject with a friendly error: "Please convert your photo to JPEG before uploading" — OR —
  - (b) Add `heic2any` as a dependency and convert HEIC→JPEG before compression.

Implement option (b). Add `heic2any` to package.json and convert HEIC inside `compressImage` before calling the main compression function.

### 2.5 Add a global file size guard
Inside `compressImage`, after compression, if the final file is still > 2 MB, reject the upload with an error. This is a safety net so a corrupt or unusually large file can't bypass compression.
