## Objective
Enhance our existing tournament bracket creation tool to match the comprehensive functionality of PrintYourBrackets.com while maintaining our current visual theme, design language, and formatting style.

## Core Requirements - Preserve Existing Design
- **CRITICAL**: Keep all existing UI components, color schemes, typography, layout patterns, and visual styling
- Maintain current user experience flow and interface structure
- Preserve any branding elements, logos, or custom design elements

## New Features to Implement

### 1. Expanded Team Capacity
- Support tournaments from **3 to 128 teams**
- Dynamically adjust bracket size based on user input
- Automatically calculate and place byes for non-power-of-2 team counts

### 2. Bracket Type Selection
Add dropdown/toggle options for:
- **Blind Draw** (no seed numbers shown)
- **Seeded** (with seed numbers 1, 2, 3, etc.)

When Seeded is selected:
- Display seed numbers on bracket positions
- Use standard seeding algorithm:
  - For 16 teams: 1v16, 8v9, 5v12, 4v13, 3v14, 6v11, 7v10, 2v15
  - Scale appropriately for other bracket sizes
  - Ensure top seeds are distributed to prevent early matchups

### 3. Bracket Direction/Layout Options
Provide user selection for:
- **Left-to-Right (Horizontal)**: Traditional flow from left side to championship on right
- **Bidirectional (Center-Meeting)**: Starts from top and bottom, converges at center for finals
- **Portrait vs Landscape**: Orientation options for printing

### 4. Tournament Format Support
Add format selection dropdown with these options:

#### **Single Elimination**
- Current standard format
- One loss = elimination
- Total games = (number of teams - 1)

#### **Double Elimination**
- Winner's Bracket and Loser's Bracket
- Teams drop to Loser's Bracket after first loss
- Must lose twice to be eliminated
- Championship: Loser's Bracket winner must beat Winner's Bracket winner twice

#### **Triple Elimination**
- Winner's Bracket, Loser's Bracket 1, Loser's Bracket 2
- Must lose three times to be eliminated
- Teams cascade down through brackets

#### **3 Game Guarantee**
- Similar to double elimination
- Special rule: Teams losing first two games get extra game in loser's bracket
- Ensures minimum 3 games per team

#### **Consolation Tournament**
- First-round winners stay in Championship Bracket
- First-round losers move to Consolation Bracket
- Two separate championship tracks

#### **Round Robin**
- Every team plays every other team
- Generate schedule/matrix format
- Track wins/losses for standings

#### **Compass Draw**
- Create sub-brackets labeled: North, South, East, West, Northeast, Northwest, Southeast, Southwest
- Losers move to different compass brackets
- Winners advance within their current bracket
- Automatically pairs similar skill levels as tournament progresses

### 5. Game Numbering System
- Add sequential game numbers (1, 2, 3...) showing order of play
- Make this optional with toggle "Show Game Numbers"
- Position numbers clearly near each matchup line

## Technical Implementation Notes

### Bracket Layout Calculations
```
For single elimination:
- Rounds = log2(next_power_of_2(teams))
- Games per round decreases by half each round
- Position byes in first round for top seeds

For double elimination:
- Winner's bracket = standard single elimination
- Loser's bracket = more complex (receives losers from winner's bracket)
- Loser's bracket has additional rounds

Seeding algorithm (standard):
- Round 1: seed[i] vs seed[bracket_size - i + 1]
- Ensures 1 vs lowest seed, 2 vs 2nd lowest, etc.
```

### Data Structure Suggestions
```javascript
bracket = {
  format: 'single-elimination',
  teams: 16,
  type: 'seeded',
  direction: 'left-to-right',
  orientation: 'landscape',
  title: 'Tournament Name',
  rounds: [
    {
      roundNumber: 1,
      games: [
        { gameNumber: 1, team1: 'Team A', team2: 'Team B', seed1: 1, seed2: 16 }
      ]
    }
  ]
}
```
