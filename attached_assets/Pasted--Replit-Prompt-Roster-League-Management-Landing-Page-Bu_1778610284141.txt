# Replit Prompt: Roster League Management Landing Page

Build a new single-scroll landing page at the route `/features` for Roster (roster-app.com). This is a high-conversion marketing page targeting hockey league commissioners, ops directors, and multi-team operators. The tone is confident, hockey-native, and modern. No mention of competitors — let the features speak for themselves.

## Design system

Match the existing Roster brand and design tokens already in the codebase. If anything below conflicts with the established design system, defer to the existing tokens.

- **Vibe:** light, clean, modern — match the existing Roster landing page theme exactly. Same background tones, same accent color usage, same button styles, same section dividers. This page should feel like a natural extension of the homepage, not a separate template. Pull existing component styles directly where possible.
- **Type:** existing Roster font stack, generous line-height, large display sizes for section headers (clamp(2.5rem, 5vw, 4.5rem))
- **Layout:** max-width ~1200px content container, with full-bleed background sections where it makes sense
- **Imagery:** real screenshots from the Roster app where possible (live bracket view, standings updating, in-game scorekeeping screen, league dashboard). Use placeholder image divs labeled clearly (e.g., `<!-- IMAGE: live bracket on iPhone -->`) where I'll drop assets later.

## Section-by-section animation strategy

Use Framer Motion (or equivalent) with scroll-triggered animations. Keep them tasteful — every section should feel intentional, never gimmicky.

- **Fade + slide-up** on text blocks as they enter viewport (translateY 24px → 0, opacity 0 → 1, 600ms ease-out)
- **Staggered children** for feature lists (80ms delay per item)
- **Parallax** on hero phone mockup and feature screenshots (subtle, ~15% offset on scroll)
- **Number counter** animation when stats scroll into view
- **Sticky scroll** section for the "League Management" feature deep-dive — the phone mockup pins while feature callouts scroll past
- **Reduced-motion respect**: all animations gated behind `prefers-reduced-motion`

## Technical notes

- Build as a new route in the existing Replit project structure — same component library, same auth shell (though this is a public marketing page, no auth required)
- Ensure mobile-first responsive: hero stacks, sticky-scroll section degrades to vertical stack on mobile
- Lazy-load below-the-fold images
- Add proper meta tags for the page: title "Roster — Features Built for Hockey Leagues", meta description "Built by a beer league captain. Roster is the all-in-one league management platform for adult recreational hockey — tournaments, scorekeeping, standings, and registration in one app."
- Open Graph image: use a Roster brand asset
- Make sure the page links from the main nav (add "Features" to the header navigation, or update the existing Features link to point here if one exists)
- Internal links: hero CTA → /start-league, pricing teaser → /pricing
- Confirm the page passes Lighthouse: target 90+ on performance, 100 on accessibility

## What NOT to do

- No competitor names anywhere on the page
- No "we're better than X" comparisons
- No corporate sports-tech jargon ("solutions," "ecosystem," "best-in-class")
- No emojis in body copy
- No fake testimonials — leave testimonial blocks out entirely until real ones exist
- No claims of scale that aren't real (don't fake user counts)
