## Permission Levels Structure

### 1. Commissioner (Primary)
- Full system access
- User management capabilities
- Can promote Secondary Commissioners
- Can assign special permissions (Admin/Stat Manager)
- League settings and configuration
- All Player Pro and Free Tier features

### 2. Secondary Commissioner
- Most Commissioner privileges
- Cannot promote other Secondary Commissioners
- Cannot demote the Primary Commissioner
- Can assign special permissions with Primary Commissioner approval
- League management access

### 3. Player Pro
- Enhanced player features
- Advanced statistics access
- Priority support
- Custom notifications
- All Free Tier features

### 4. Free Tier
- Basic player access
- Standard game participation
- Limited statistics view
- Standard notifications

### 5. Special Permissions (Additional Roles)
- **Admin**: Can input and modify game scores/results
- **Stat Manager**: Can update player statistics and records
