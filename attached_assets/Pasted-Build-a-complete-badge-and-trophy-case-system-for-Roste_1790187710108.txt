Build a complete badge and trophy case system for Roster Hockey, a hockey team and league management iOS/Android app built in React Native. This document is the full specification. Build exactly what is described here — do not simplify, do not make assumptions, do not substitute libraries without noting it.

SYSTEM OVERVIEW

Players earn badges across three categories. Badges live in a Trophy Case on their profile. When a badge is earned, a modal interrupts the current screen to present it. All badges are hidden until earned — shown as a silhouette with a ?. Progress bars appear under unearned tiered badges so players know they are making progress even though the badge is locked.

The system is fully data-driven. Adding a new badge, a new tier, or a new category requires zero changes to component code — only config file edits.

BADGE CATEGORIES & TYPES

Category 1 — NHL Trophy Patches
League-wide awards identical to real NHL awards (Hart, Vezina, Norris, Art Ross, Maurice Richard, Lady Byng, Selke, Conn Smythe, William Jennings, Jack Adams). Awarded manually by league admins. One-time. No progress bar.

Category 2 — Team Badges
Awarded by team captains to individual players. One-time per season. No progress bar. Default badges: The Bender, The Architect, The Brick Wall, The Enforcer, The Sniper, The Houseplant, The Iron Man. Captains can also create custom badges.

Category 3 — Achievements
Three sub-types:

Multiplier — earned repeatedly, counter increments. Badges: RSVP King, Team Player.
Tiered — four tiers (Bronze → Silver → Gold → Platinum). Beer Me has five tiers (Bronze → Silver → Gold → Platinum → Legend). Badges: Hat Trick, Iron Man, Century Club, Broom, Beer Me, On Fire, 3 Stars.
One-time — unlocks once permanently. Badges: Rookie Card, Sub, League Hopper, Early Bird, Ghost, Sub Magnet.

type AchievementType = 'multiplier' | 'tiered' | 'onetime';

TRIGGER ARCHITECTURE
Core principle
User action → StatService.update() → BadgeEvaluator.evaluate() → Award if threshold met → BadgeEventBus.emit() → Modal fires

No feature ever calls awardBadge() directly. Features update stats. The evaluator handles everything else.

StatService

// /services/StatService.ts

class StatService {
  async update(playerId: string, updates: Partial<PlayerStats>): Promise<void> {
    const updatedStats = await StatRepository.update(playerId, updates);
    await BadgeEvaluator.evaluate(playerId, updatedStats);
  }

  async recordGame(playerId: string, didPlay: boolean) {
    if (didPlay) {
      await this.update(playerId, {
        career_games_played: increment(1),
        consecutive_games_played: increment(1),
        consecutive_games_out: 0,
      });
    } else {
      await this.update(playerId, {
        consecutive_games_out: increment(1),
        consecutive_games_played: 0,
        scoring_streak_games: 0,
      });
    }
  }

  async recordHatTrick(playerId: string) {
    await this.update(playerId, { career_hat_tricks: increment(1) });
  }

  async recordPoint(playerId: string) {
    await this.update(playerId, { scoring_streak_games: increment(1) });
  }

  async recordNoPoint(playerId: string) {
    await this.update(playerId, { scoring_streak_games: 0 });
  }

  async recordShutout(playerId: string) {
    await this.update(playerId, { career_shutouts: increment(1) });
  }

  async recordThreeStars(playerId: string) {
    await this.update(playerId, { career_three_stars: increment(1) });
  }

  async recordSubAppearance(playerId: string) {
    await this.update(playerId, {
      career_sub_appearances: increment(1),
      first_sub_appearance: true,
    });
  }

  async recordLeagueJoined(playerId: string) {
    await this.update(playerId, { career_leagues_played: increment(1) });
  }

  async recordFirstGame(playerId: string) {
    await this.update(playerId, {
      career_games_played: increment(1),
      first_game_logged: true,
    });
  }

  async recordBeer(playerId: string) {
    await this.update(playerId, { season_beers: increment(1) });
  }

  async recordRsvp(playerId: string, hoursBeforeGame: number) {
    if (hoursBeforeGame >= 48) {
      await this.update(playerId, { season_first_rsvp_streak: true });
    } else {
      await this.update(playerId, { season_first_rsvp_streak: false });
    }
  }
}
BadgeEvaluator
typescript
// /services/BadgeEvaluator.ts

class BadgeEvaluator {
  async evaluate(playerId: string, stats: PlayerStats): Promise<void> {
    const playerBadges = await BadgeRepository.getPlayerBadges(playerId);

    for (const [badgeId, trigger] of Object.entries(BADGE_TRIGGERS)) {
      const definition = BADGE_REGISTRY.find(b => b.id === badgeId);
      if (!definition) continue;

      switch (trigger.type) {
        case 'tiered':
          await this.evaluateTiered(playerId, badgeId, definition, trigger, stats, playerBadges);
          break;
        case 'multiplier':
          await this.evaluateMultiplier(playerId, badgeId, trigger, stats, playerBadges);
          break;
        case 'onetime':
          await this.evaluateOnetime(playerId, badgeId, trigger, stats, playerBadges);
          break;
      }
    }
  }

  private async evaluateTiered(playerId, badgeId, definition, trigger, stats, playerBadges) {
    const currentValue = stats[trigger.stat];
    const earnedTiers = playerBadges[badgeId]?.earnedTiers ?? [];

    for (const tierDef of definition.tiers) {
      if (earnedTiers.includes(tierDef.tier)) continue;
      if (currentValue >= tierDef.threshold) {
        await this.award(playerId, badgeId, tierDef.tier);
      }
    }
  }

  private async evaluateMultiplier(playerId, badgeId, trigger, stats, playerBadges) {
    const currentValue = stats[trigger.stat];
    const lastCount = playerBadges[badgeId]?.count ?? 0;
    if (currentValue > lastCount) {
      await this.award(playerId, badgeId, null, currentValue);
    }
  }

  private async evaluateOnetime(playerId, badgeId, trigger, stats, playerBadges) {
    if (playerBadges[badgeId]?.isEarned) return;
    const condition = trigger.stat
      ? stats[trigger.stat] >= (trigger.threshold ?? 1)
      : stats[trigger.event] === true;
    if (condition) {
      await this.award(playerId, badgeId);
    }
  }

  private async award(playerId, badgeId, tier?, count?) {
    await BadgeRepository.recordAward(playerId, badgeId, tier, count);
    BadgeEventBus.emit('badge_earned', { playerId, badgeId, tier, count });
  }
}

// /jobs/EndOfSeasonJob.ts

async function runEndOfSeasonJob(seasonId: string) {
  // Award RSVP King to players with perfect 48hr streak all season
  const rsvpKingPlayers = await getPlayersWithPerfectRsvpStreak(seasonId);
  for (const playerId of rsvpKingPlayers) {
    await StatService.update(playerId, { season_first_rsvp_streak: true });
  }

  // Award Sub Magnet to the player with the most subs filled in for them
  const subMagnetWinner = await getPlayerWithMostSubs(seasonId);
  await StatService.update(subMagnetWinner.id, { season_most_subs_winner: true });

  // Reset all season-scoped stats
  await StatRepository.resetSeasonStats(seasonId);
}

EXTENSIBILITY RULES

These rules must be followed throughout the implementation:

BADGE_REGISTRY is the single source of truth. Components read from it exclusively — no badge IDs or names hardcoded anywhere in component code
TIER_CONFIG is the single source of truth for tier colors — no tier colors hardcoded in components
CATEGORY_CONFIG drives trophy case sections — adding a new entry automatically creates a new section
BADGE_TRIGGERS drives all evaluation logic — adding a new trigger entry is all that's needed to wire up a new badge
StatService.update() is the only entry point for stat changes
BadgeEvaluator.evaluate() is called exclusively by StatService
The BadgeEarnedModal accepts badge data as props — it has zero knowledge of specific badge IDs
No switch statements or if/else chains on badge type in components — behavior is inferred from the shape of the BadgeDefinition object (presence of tiers array = tiered, presence of count = multiplier)

To add a new badge: drop PNG in /assets/badges/, add entry to BADGE_REGISTRY, add trigger to BADGE_TRIGGERS, ensure relevant stat exists in PlayerStats. Zero component changes.

To add a new tier to an existing badge: drop PNG in /assets/badges/, add tier object to that badge's tiers array. Everything else is automatic.

To add a new tier type: add entry to TIER_CONFIG. Done.

To add a new badge category: add entry to CATEGORY_CONFIG. A new section appears in the trophy case automatically.
