Context: Roster is a React + TypeScript (Vite) web app that runs both in normal browsers and inside Natively iOS/Android WebView wrappers. On mobile, in-app purchases go through Natively's native purchase bridge to RevenueCat (Apple App Store billing on iOS, Google Play on Android). This bridge already works for existing purchases — reuse it. Do NOT add @revenuecat/purchases-js, Stripe, or any web-checkout flow for the in-app purchase path, because inside the wrappers, digital-goods purchases must go through native store IAP or Apple/Google will reject the app.
