Revert root padding changes in client/src/index.css
Earlier CSS edits added padding-top / padding-bottom to #root using env(safe-area-inset-*) to handle status bar and navigation bar insets. This conflicted with the Natively native wrapper's own safe-area handling and caused inconsistent top padding across navigation events (padding present on initial load, missing after navigating away and back to a screen).
The Natively wrapper will now handle insets at the native level via its Safe Area dashboard setting. CSS-side padding on #root needs to be removed.
Make exactly this one change. Do not touch anything else.
