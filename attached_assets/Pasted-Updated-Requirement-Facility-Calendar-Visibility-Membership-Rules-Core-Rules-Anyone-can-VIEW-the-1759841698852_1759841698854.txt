Updated Requirement: Facility Calendar Visibility & Membership Rules
Core Rules

Anyone can VIEW the facility's full calendar (all sports, all events)
Only facility MEMBERS can participate/get invites (for any sport at that facility)
This applies across ALL sports - membership grants access to everything at the facility

Why This Matters

Discovery: Non-members can see what's happening to decide if they want to join
Transparency: Shows facility activity levels and variety of offerings
Conversion: Seeing active leagues/scrimmages encourages facility membership
Cross-sport participation: Members can explore different sports offered


Updated Calendar Visibility & Access Rules
1. Public View (No Login/Membership Required)
CAN:

Browse facility calendar (all sports, all events)
See league schedules across all sports
View scrimmage listings
See time slots and availability
View facility information and contact details
See "Join this facility" call-to-action

CANNOT:

Join scrimmages
RSVP to events
Receive invites
See participant lists
Access contact info of other members

2. Facility Member View (Facility Membership Required)
CAN:

Everything public users can see PLUS:
Join scrimmages for ANY sport at the facility
RSVP to open play sessions
Receive invites to facility events
See participant counts/lists
Contact other members
Create/host scrimmages
Access member-only events

CANNOT:

Join league games (requires team roster spot)
Access league-specific team communications (requires team membership)

3. League Participant View (League Team Membership Required)
CAN:

Everything facility members can see PLUS:
Access team-specific game details
Team chat/communications
Score entry (if authorized)
Opponent roster information
League standings

Note: League participation REQUIRES facility membership as a prerequisite

Access Control Logic
Add to Phase 5 (Access Control):
javascript// Pseudo-code for event participation check

function canUserJoinEvent(user, event, facility) {
  // Check 1: Is user a member of this facility?
  if (!isFacilityMember(user, facility)) {
    return {
      canJoin: false,
      reason: "MEMBERSHIP_REQUIRED",
      message: "Join this facility to participate in events"
    };
  }
  
  // Check 2: What type of event?
  if (event.type === 'SCRIMMAGE' || event.type === 'OPEN_PLAY') {
    // Facility membership is sufficient
    return {
      canJoin: true,
      accessLevel: "FACILITY_MEMBER"
    };
  }
  
  if (event.type === 'LEAGUE_GAME') {
    // Requires team roster spot
    if (!isOnTeamRoster(user, event.team_id)) {
      return {
        canJoin: false,
        reason: "TEAM_ROSTER_REQUIRED",
        message: "League games require team membership"
      };
    }
    return {
      canJoin: true,
      accessLevel: "LEAGUE_PARTICIPANT"
    };
  }
}

function canUserViewEvent(user, event) {
  // Everyone can VIEW all events
  return true;
}
Updated API Endpoints
Calendar Viewing (Public):
GET /api/facilities/{id}/calendar
- No auth required
- Returns all events across all sports
- Include CTAs for non-members
- Show "Members only" badges on actionable items
Event Participation (Members Only):
POST /api/facilities/{facilityId}/scrimmages/{scrimmageId}/join
- Requires auth
- Checks facility membership
- Returns 403 if not a member with message about joining facility

POST /api/facilities/{facilityId}/events/{eventId}/rsvp
- Requires auth
- Checks facility membership
- Returns appropriate error with join facility CTA

User Flow Examples
Non-Member Journey:

Browse facility → See calendar with all sports
Click on interesting scrimmage → See details
Click "Join" → Prompted to become facility member first
Complete membership signup → Now can join events

Member Journey:

Member of Facility A
Browse Facility A calendar → See basketball, soccer, volleyball
Usually plays basketball
See interesting soccer scrimmage → Click join (no extra signup!)
Now participating in soccer scrimmage

Multi-Facility User:

Member at Facility A and Facility B
Browse Facility C calendar → Can view all events
Try to join Facility C event → Must join Facility C first
Membership at A and B doesn't grant access to C
